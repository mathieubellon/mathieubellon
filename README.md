# Hi, I'm Mathieu Bellon

Senior Product Manager at [GitGuardian](https://github.com/GitGuardian) · Rennes, France

I build products and developer tools around AI agents. I'm interested in how agents work with software and data, and what it takes to make their actions useful and reliable.

At GitGuardian, I work on secret detection and non-human identity (NHI) security, including bringing security workflows into coding agents.

## AI & agents

- Writing reusable skills and workflows for coding agents such as Claude Code, Codex, and Cursor.
- Connecting agents to existing tools and data through MCP (Model Context Protocol).
- Evaluating agent behavior, defining permissions, and keeping people involved in sensitive actions.
- Building tools that turn natural language into actions developers can inspect and run.

## Projects I build or contribute to

- [GitGuardian Agent Skills](https://github.com/GitGuardian/agent-skills): skills that teach coding agents to scan for secrets, help remediate incidents, and set up prevention.
- [GitGuardian MCP server](https://github.com/GitGuardian/ggmcp): access to GitGuardian security data and actions from AI assistants.
- [clai](https://github.com/mathieubellon/clai): a command-line assistant that turns natural language into shell commands you can review, explain, and run.
- [Moltbook Scanner](https://github.com/mathieubellon/moltbook-scanner): a toolkit for browsing an AI-agent social network and finding exposed API keys.
